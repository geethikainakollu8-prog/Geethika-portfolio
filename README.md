# Geethika Inakollu — Portfolio

A responsive React + Vite portfolio with an original midnight-blue and violet visual identity.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder and open it in VS Code.
3. Open a terminal in this folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build for deployment

```bash
npm run build
```

The production site is generated in the `dist` folder. Vercel can deploy this Vite project directly; use `npm run build` as the build command and `dist` as the output directory.


## Personalise before publishing

Edit `src/main.jsx`:

- Update the profile details in the `profile` object.
- Add each project's own GitHub repository URL when it is ready. Project cards currently link to the general GitHub profile rather than individual repositories.
- Add links to certificate files or verification pages when available.
- Review every skill and project description so it reflects your current experience accurately.

The site uses public Google Fonts and the `lucide-react` icon package.
